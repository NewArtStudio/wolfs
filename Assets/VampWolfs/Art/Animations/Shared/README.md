# Animações compartilhadas (humanoides)

Animações usadas pelos três personagens (lobisomem, vampiro, caçador) via retarget Humanoid da Unity.

## Lista para baixar do Mixamo (mixamo.com, grátis, uso comercial liberado)

Configuração de download de cada uma:
- **Format:** FBX for Unity
- **Skin:** Without Skin
- **Frames per second:** 30
- **Keyframe reduction:** none
- Marque **In Place** sempre que a opção aparecer (o jogo é quem move o personagem).

Renomeie o arquivo para o nome da coluna "Arquivo":

| Arquivo | Uso no jogo | Busca sugerida no Mixamo |
|---|---|---|
| `Idle.fbx` | parado | "Idle" ou "Breathing Idle" |
| `CombatIdle.fbx` | parado em combate | "Fighting Idle" |
| `Run.fbx` | correr para frente | "Running" (In Place) |
| `RunBack.fbx` | correr de costas (mirando para trás) | "Running Backward" (In Place) |
| `StrafeLeft.fbx` | correr de lado | "Left Strafe" (In Place) |
| `StrafeRight.fbx` | correr de lado | "Right Strafe" (In Place) |
| `Dash.fbx` | dash / esquiva | "Roll" ou "Sprinting Forward Roll" |
| `Jump.fbx` | bote / salto | "Jump Attack" ou "Jumping" |
| `Attack1.fbx` | ataque básico (M1) | "Sword And Shield Slash" ou "Punching" |
| `Attack2.fbx` | ataque pesado (M2) | "Great Sword Slash" ou "Mutant Swiping" |
| `Cast.fbx` | lançar magia / projétil | "Standing 1H Magic Attack" |
| `CastArea.fbx` | habilidade em área | "Standing 2H Magic Area Attack" |
| `Block.fbx` | counter / defesa | "Standing Block Idle" |
| `Hit.fbx` | levar dano | "Hit Reaction" |
| `Stunned.fbx` | atordoado | "Dizzy Idle" |
| `Death.fbx` | morte | "Dying" |
| `Howl.fbx` | uivo do lobisomem (opcional) | "Mutant Roaring" |

Não precisa ter todas para começar: **Idle, Run, Attack1, Cast, Hit e Death** já deixam o jogo vivo. O resto entra depois.
